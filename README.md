# Codex Quota Tray

**Version:** v1.0

Codex Quota Tray is a lightweight Windows notification-area app for monitoring Codex quota from local session logs, with no API key or network connection required. Both the C# and PowerShell versions show rounded quota bars and readable percentage/reset cards inspired by the macOS app.

For the macOS version, see [PlutaB/codex-quota-menubar](https://github.com/PlutaB/codex-quota-menubar).


## Run

### Executable

Open the repository's **Actions** tab, select a successful **Build Windows tray app** run, and download the **CodexQuotaTray-Windows** artifact. Extract the ZIP and double-click `CodexQuotaTray.exe`. Binaries are generated by CI, not committed to the repository.

The indicator appears in the lower-right notification area (it may initially be in the `^` overflow menu). Left-click or right-click for quota details, refresh, session-log folder access, startup toggle, and quit.

### PowerShell

Alternatively, run `Run-CodexQuotaTray.cmd` or:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\CodexQuotaTray.ps1
```

### Build and test locally

Requires Windows with .NET Framework 4.8 and Windows PowerShell 5.1. No additional packages are needed.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1 -Test
.\bin\CodexQuotaTray.exe
```

Omit `-Test` to only compile. The tests exercise both C# and PowerShell UI rendering without reading real session logs. GitHub Actions runs the same build/tests on pushes, pull requests, and manual dispatch, then uploads the executable.

The indicator shows the first two quota windows in ascending duration (normally 5-hour and 7-day). Green means at least 40% remaining, amber means 20–39%, and red means below 20%.


## Command-line check

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\CodexQuotaTray.ps1 -Once
```


## Startup

Right-click the tray icon and choose **Start at login**. This creates/removes a per-user Run registry entry, pointing to the executable or script you are running. Enable it from only one version. Keep the folder in a permanent location if enabling this option.
